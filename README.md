# 学习笔记 V6

## V6 新增：目录切换时自动关闭其它标签

现在左侧目录作为主要导航使用。

当你点击某一篇笔记时：
- 自动保存当前已打开的其它笔记
- 自动关闭其它标签页
- 只保留你刚刚选择的这一篇笔记

这样使用目录切换内容时，不会不断累积一堆标签页。

新建笔记时也会：
- 保存当前笔记
- 关闭其它标签
- 只打开新建的笔记
