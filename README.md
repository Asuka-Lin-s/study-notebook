# 学习笔记 V7

## V7 新增：层级目录

左侧目录已经升级为树形结构：

```text
▼ ESP32 学习
    ▼ 基础
        GPIO
        I2C
        SPI
    ▼ 显示
        OLED
        LCD
▶ STM32 学习
▶ 电路分析
```

支持：
- 新建文件夹
- 文件夹中继续新建子文件夹
- 文件夹中创建笔记
- 展开 / 收起文件夹
- 自动记住文件夹展开状态
- 拖拽笔记或文件夹调整层级
- 拖拽调整同级顺序
- 搜索时保留匹配笔记及其父级路径
- 删除文件夹时会提示其中包含的笔记数量

旧版本已有笔记会自动作为根目录笔记保留，不需要手动迁移。

## V7 新增：正文标题层级

编辑区顶部新增“段落”选择：

- 正文
- H1 一级标题
- H2 二级标题
- H3 三级标题

快捷键：

- `Ctrl+0`：正文
- `Ctrl+1`：H1 一级标题
- `Ctrl+2`：H2 二级标题
- `Ctrl+3`：H3 三级标题

标题层级会直接保存在笔记 HTML 中，因此导出后也能保留标题结构。

这一版先建立标题体系；后续可以继续在此基础上实现正文标题的展开 / 收起。

## 原有功能

- 左侧目录可隐藏 / 恢复
- 多篇笔记独立保存
- 目录切换时自动保存并关闭其他标签
- 标签页界面
- 搜索上一个 / 下一个
- 搜索关键词高亮
- `F3` / `Shift+F3`
- 区域截图
- `Ctrl+V` 粘贴图片
- 图片双击放大
- 自动保存
- HTML / TXT 导出
- 四边和四角自由缩放
- 屏幕边缘吸附隐藏
- 置顶

`StudyNotebook-Windows-x64`

`StudyNotebook.exe`
